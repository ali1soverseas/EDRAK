## 1. Executive Positioning Matrix
| Dimension | GitLab Duo Agent Platform | GitHub Copilot / Copilot Workspace |
| :--- | :--- | :--- |
| **Scope of Automation** | Full DevSecOps lifecycle (Planning ➔ Code ➔ Review ➔ Security Remediation ➔ CI/CD Triage) | Predominantly IDE/editor-centric coding assistant with emerging GitHub Workspace issue triage |
| **Data Model & Context** | Single unified database with full visibility into Epics, MRs, SAST alerts, and pipeline logs | Modular multi-tool integration requiring third-party plugins for full ALM context |
| **Model & Cloud Neutrality** | Multi-model routing (Anthropic Claude 3.5, GPT-4o, GLM) + Self-Hosted local LLMs | Microsoft Azure OpenAI / OpenAI model dependency; limited air-gapped on-prem options |
| **Data Privacy & Air-Gap** | GitLab Duo Self-Hosted enables complete offline, customer-managed inference with no external telemetry | Managed cloud service with strict enterprise cloud terms, but no full on-prem self-hosted model choice |
| **Monetization Architecture** | Base tier bundled credits + consumption-based GitLab Credits with Flex Commitments | Flat per-user add-on pricing ($19/user/mo for Business, $39/user/mo for Enterprise) |
