Which version is best on each metric?

Each metric is averaged over the workers and stages (workers with no findings are left out). A difference of or less counts as a tie.

Score for each worker and stage

Worker rows show how many findings each version produced (first / second). Faded rows had no findings, so they are not scored. On the right: the Optimized score, the GraphRAG score, and the difference (second minus first).

Who wins each metric, for each worker and stage

The color shows which version scored higher, and the number shows by how much. Stronger color means a bigger gap. Hover over a cell to see both scores.

Score = correctness 30% + faithfulness 30% + completeness 25% + coverage 15%. The overall score is the simple average of the scored workers and stages. This is a practical comparison, not a statistical test.
